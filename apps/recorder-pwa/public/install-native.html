CrewSight Manager

Coach / ops monitor — live fleet map, session history, and background capsize alerts while monitoring is on. The web dashboard is also available in a browser.

arm64 build (~10 MB). Allow notifications for capsize alerts when the app is in the background.

Install steps

Use Samsung Internet or Chrome. If a download stalls, use USB (below).

  1. Download the APK for the app you need (or both — they install separately).
  2. Open the file and tap Install.
  3. If blocked, allow installs from your browser in Android settings.
  4. CrewSight: grant location (Always), motion, and notifications; enter device ID and start a session.
  5. CrewSight Manager: set API URL and token if required; tap Start monitoring on the water.
For sideloading from a PC, copy the APK to the phone and open it with Files or My Files.

USB install (adb)

Enable USB debugging, connect the phone, then run on your computer:

adb install -r CrewSight.apk
adb install -r CrewSight-Manager.apk
