CrewSight Manager

Coach / ops monitor — live fleet map, session history, and capsize alerts while the app is open. On iPhone, use the web app (Add to Home Screen). On Android, the native APK adds background capsize alerts while monitoring is on. The desktop dashboard is also available in a browser.

Android APK: arm64 build (~10 MB). Allow notifications for capsize alerts when the app is in the background.

Android install guide (CrewSight)

Use Chrome or Samsung Internet. Screenshots are from a Samsung phone; other Androids are similar. If a download stalls, use USB (below).

CrewSight is not on the Play Store yet. Google Play Protect may warn that it has not seen this developer — that is expected. Choose Install anyway (not OK).

1Download the APK

On this page, tap Download CrewSight.apk above (or open the download from Chrome).

2Open the file

Open My Files → Downloads (or Chrome’s download notification). Tap the latest CrewSight APK.

3Install

When asked “Do you want to install this app?”, tap Install.

4Bypass Play Protect (if shown)

If Play Protect blocks the install, tap More details, then Install anyway. Do not tap OK — that cancels the install.

5Open the app

When you see App installed, tap Open.

6Allow notifications

Tap Allow so capsize and session alerts can reach you.

7Allow location (precise)

Choose Precise, then While using the app. Next, set location to Allow all the time and leave Use precise location on — background GPS needs this while you row.

8Allow background battery use

When asked “Stop optimising battery usage?”, tap Allow so tracking continues with the screen off.

9Confirm the home screen

You should see the CrewSight home screen with Start session and Settings.

10Set Device ID

Tap Settings. Enter your club Device ID (e.g. boat/phone label). Leave the ingest URL as provided unless your coach gives a different one. Save, then return and tap Start session when you go on the water.

11Optional checks (recommended)

Phone Settings → Apps → CrewSight: confirm Location and Notifications are allowed. Under mobile data for the app, keep Allow background data usage on so uploads work away from Wi‑Fi. Ensure Mobile data is on when you are on the water.

For sideloading from a PC, copy the APK to the phone and open it with Files or My Files.

USB install (adb)

Enable USB debugging, connect the phone, then run on your computer:

adb install -r CrewSight.apk
adb install -r CrewSight-Manager.apk
